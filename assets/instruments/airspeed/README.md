# Airspeed-style groundspeed instrument

The original photographic face, needle, scale and runtime speed mapping are
unchanged. `airspeed-range-ink.svg` is a registered, transparent vector ink
layer over that face and below its existing illumination and moving needle.
It uses the original 1254×1254 canvas, center (627, 627), and 45 degrees per
100 knots. Fixed, translucent pinholes give the paint restrained print wear
without animation or resolution-dependent raster edges.

Joey approved these **illustrative** aircraft-inspired markings:

- Red radial: 110 knots.
- Yellow: 110–125 knots.
- Green: 125–350 knots, narrowing progressively from 300 to 350.
- Separate ivory flap-style arc: 110–165 knots.

These are not aircraft operating limitations or stall/overspeed warnings.
The instrument displays **groundspeed**, not indicated airspeed. There is
no high-speed redline, barber pole, warning state, or flight-data change.
The existing runtime needle cap of 700 knots is unchanged.

Browser artwork checks verify visible colors at registered positions,
transparent space beyond the arcs, and needle stacking across all five
full-display layouts. The kiosk proof includes `airspeed-detail.png`.
