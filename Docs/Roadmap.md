# DadRadar roadmap

Updated September 19, 2026. Current implementation is documented in the [build handoff](Current-build-handoff.md); this roadmap is not a second architecture specification.

Completed family-beta capabilities include Calendar planning, one home-server state, ADSB.lol tracking with optional FR24 fallback, optional FlightAware operational/filed-route enrichment, family access, approved physical artwork, continuous map transport, overnight modules, live gauges, audio, and automatic display refresh.

The present maintenance milestone is repository cleanup: accurate documentation, retired experiment removal, current-browser verification and preserved branch history. See the [cleanup result](Repository-cleanup-2026-09-19.md).

Future work requires Joey’s prioritization: physical faceplate construction and alignment, further field reliability evidence, and eventual commercial provider rights/economics. The [feature backlog](Feature-backlog.md) records ideas rather than authorization to implement them.
